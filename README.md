# Kay Amazing Grace

Premium Okirika and thrift bale supplier in Aba, Nigeria. A product catalogue, order enquiry flow and a full admin console behind it, built to run on a phone.

![Kay Amazing Grace storefront](docs/screenshots/storefront.png)

Live: https://kay-amazing-grace-two.vercel.app

## The problem

Bale and thrift trading runs on WhatsApp screenshots and voice notes. Buyers cannot see what is in stock, and the seller republishes the same photos every week. This storefront gives the business a catalogue that stays current, a place to send buyers, and a way to capture enquiries instead of losing them in chat.

## What is inside

- *Catalogue*: bale categories, featured products and a new arrivals feed
- *Product detail*: images, pricing per bale, minimum order and description
- *Enquiries*: buyer enquiry capture with the product attached, so no lead is lost
- *Reviews*: customer reviews with moderation
- *Gallery*: lookbook images for social traffic
- *SEO landing pages*: dedicated pages for Okirika bales Aba and thrift bales Nigeria, targeting how buyers actually search
- *Admin console*: product management, new arrivals, gallery, reviews, enquiries and site settings behind an authenticated guard
- *Mobile first*: search overlay, sticky navigation and a social bar tuned for phone traffic

## Stack

React, JavaScript, Vite, managed backend (entities, auth, serverless functions), deployed on Vercel
